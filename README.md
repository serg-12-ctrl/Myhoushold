# myhousehold# Backend-сервис «Менеджер домашних запасов»

Бэкенд-система для управления домашними продуктами и бытовыми товарами с учетом партий, сроков годности и продвинутых стратегий списания (FEFO/FIFO).

## Реализованный функционал
- **JWT-авторизация:** Регистрация, логин и получение профиля пользователя.
- **Учет партий:** Один товар может храниться в разных местах (холодильник, кладовая) и иметь разные сроки годности.
- **Движок списаний:** Поддержка стратегий `expires_first` (FEFO) и `oldest_first` (FIFO) с автоматическим каскадным распределением по партиям и транзакционными блокировками `select_for_update` (защита от Race Conditions).
- **Логирование:** Любое изменение остатка фиксируется в неудаляемом журнале операций.
- **Фоновые задачи (Celery + Redis):** Спроектированы задачи для ежедневной проверки просрочки и расчета прогноза окончания продуктов.

## Запуск проекта локально
1. Активируйте окружение и установите зависимости:
   ```bash
   .\myenv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Примените миграции базы данных:
   ```bash
   python manage.py migrate
   ```
3. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```

## Запуск тестов
Для проверки корректности бизнес-логики выполните:
```bash
python -m pytest
```
